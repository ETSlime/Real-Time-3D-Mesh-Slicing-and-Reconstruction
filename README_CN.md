# Mesh Cut

**基于 C++ 与 DirectX 11 的交互式网格切割。**

[English](README.md) · [日本語](README_JP.md) · **中文**

在三维模型上拖动鼠标，裁剪三角形网格、恢复截面轮廓并生成两侧封口。可以撤销和重做切割，拖入另一个 OBJ 更换模型，并通过实心或线框模式检查结果。

## 主要功能

- **交互式平面切割：** 鼠标拖动确定经过透视相机的切割平面。
- **表面重建：** 半空间裁剪生成两侧网格，插值位置、法线、顶点色与 UV。
- **基于轮廓的封口：** 交点合并与邻接关系恢复闭环，耳切法支持简单凹轮廓及多个独立非嵌套轮廓。
- **多材质与碎块切割：** 同一碎块跨材质恢复完整轮廓；持久碎块编号支持只切目标碎块，未切部分保持原位。生成表面与封口可以继续切割。
- **撤销／重做：** 两个快照栈恢复几何与材质；撤销后成功进行新切割会清空旧重做分支。
- **OBJ 拖放：** 加载成功后替换模型，重置展示状态与相机并清空编辑历史；加载失败保留当前模型和历史。
- **结果观察：** F1 切换实心／线框，F3 切换切割平面预览。Debug 与 Release 都显示操作提示。
- **分阶段资源替换：** 新 CPU 数组与 GPU 缓冲准备完成后，才释放当前显示模型。

## 操作方式

| 输入 | 功能 |
|---|---|
| 鼠标左键拖动并释放 | 尝试切割 |
| 拖入单个 `.obj` | 成功后替换并重置模型、清空历史 |
| 重新拖入同一个 OBJ | 重新加载原始几何 |
| Ctrl + Z | 撤销 |
| Ctrl + Y / Ctrl + Shift + Z | 重做 |
| F1 | 实心／线框切换 |
| F3 | 显示／隐藏切割平面预览 |
| 方向键 | 相对相机朝向移动模型 |
| Esc | 退出 |

相机与展示操作（Debug／Release 均有效）：

| 输入 | 功能 |
|---|---|
| A / D | 相机水平旋回 |
| W / N | 相机升高／降低 |
| U / M | 相机靠近／远离 |
| R | 重置模型变换与相机，保留已经切割的几何 |

左右 Ctrl／Shift 均可。每次按下 Z／Y 只执行一次历史操作；拖动切割线期间忽略这些快捷键。撤销／重做恢复网格状态，不恢复相机或模型展示变换。成功恢复后清除旧平面预览，但保留预览显示开关。

F3 展示最近尝试生成的切割平面，预览可见并不表示切割一定成功。R 只重置展示状态；要恢复原始几何，可以重新拖入 OBJ。

## 构建与运行

1. 在 Windows 中打开 Visual Studio 解决方案／项目，使用 C++17。
2. 配置项目使用的 DirectX 11、DirectXMath、输入和 D3DX11 依赖，包括对应头文件、库及运行时依赖。
3. 确认 Shader 与资产路径可以从项目工作目录解析，然后构建运行。
4. 拖入预先三角化、闭合、包含法线与 UV，并具有有效 MTL／贴图引用的 OBJ。
5. 切割模型，用 F1 检查三角形，并通过 Ctrl+Z／Ctrl+Y 比较编辑状态。

MTL 与贴图应放在资产引用的位置。导入器面向既定的 OBJ／MTL 格式；ASCII 路径及不含空格的引用文件名最便于测试。拖放路径会转换为加载器使用的 Windows ANSI 代码页，不是完整的 Unicode 路径导入流程。

## 模块结构

| 模块 | 职责 |
|---|---|
| `MeshCutter.h / .cpp / .inl` | 几何、坐标辅助、裁剪、轮廓、三角化与封口 |
| `ObjImporter` | OBJ／MTL 解析与 CPU 模型数据 |
| `ModelSnapshot.h / .cpp` | 捕获／恢复模型状态，持有纹理引用 |
| `ModelHistory.h / .cpp` | 两个历史栈、切割记录提交、撤销／重做与清空 |
| `player.cpp` | 鼠标交互、subset 暂存、模型更新与历史接入 |
| `renderer.cpp` | 渲染资源、填充／剔除状态与文字绘制 |
| `camera.cpp` | 透视相机与重置 |

## 当前范围与限制

- 面向闭合、外向绕序一致、无自交的流形网格；不提供通用网格修复。
- 支持平面切割、简单凹截面与多个独立非嵌套闭环；不支持带孔截面或任意实体布尔运算。
- 相切可保持未变化；实际分割中的整面共面、歧义连接或无法安全三角化时，保留当前有效模型。
- 顶点以 float 保存；有限容差与最多两次局部细化不保证任意尺度、极窄特征或无限次切割。所需平面修复若会破坏超出容差的 UV／颜色特征，也可拒绝。
- 当前应用最多接受 65,535 个展开顶点。历史保存完整 CPU 几何与碎块编号，尚无数量／内存预算或持久化；纹理引用共享。
- 碎块编号保持已识别碎块独立，不进行重叠碎块求并、碰撞或刚体模拟。

建议展示顺序：立方体切割 → 多材质跨组封口 → L 棱柱凹截面 → 只切中间碎块 → 撤销／重做 → F1／F3 检查 → 重新拖入 OBJ。
