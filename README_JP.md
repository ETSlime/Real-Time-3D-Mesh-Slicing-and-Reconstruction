# Mesh Cut

**C++ と DirectX 11 によるインタラクティブなメッシュ切断。**

[English](README.md) · **日本語** · [中文](README_CN.md)

3Dモデル上でマウスをドラッグし、三角形メッシュを切り分け、断面輪郭から両側の切断面を生成します。切断の取り消し／やり直し、OBJのドロップによるモデル切り替え、塗りつぶし／ワイヤーフレームでの結果確認に対応します。

## 主な機能

- **平面による対話的切断：** マウス操作から透視カメラを通る切断平面を決定します。
- **表面の再構築：** 半空間クリッピングで両側を生成し、位置、法線、頂点色、UVを補間します。
- **輪郭に基づく切断面生成：** 交点統合と隣接関係から閉輪郭を復元し、耳切り法で単純な凹輪郭や独立した非入れ子輪郭を分割します。
- **再切断：** 生成後の表面と切断面も、次の切断対象になります。
- **取り消し／やり直し：** 2つのスナップショットスタックで形状と材質を復元します。取り消し後に新しい切断が成功すると、以前のやり直し分岐を破棄します。
- **OBJドラッグ＆ドロップ：** 成功時はモデルを置換し、表示状態とカメラをリセットして履歴を消去します。失敗時は現在のモデルと履歴を維持します。
- **結果確認：** F1で塗りつぶし／ワイヤーフレーム、F3で切断平面プレビューを切り替えます。操作ガイドはDebug／Releaseの両方で表示します。
- **段階的なリソース置換：** 新しいCPU配列とGPUバッファの準備後に、表示中のモデルを解放します。

## 操作方法

| 入力 | 操作 |
|---|---|
| 左ドラッグ後に解放 | 切断を試行 |
| 単一の `.obj` をドロップ | 成功時にモデルを置換・リセットし、履歴を消去 |
| 同じOBJを再ドロップ | 元の形状を再読み込み |
| Ctrl + Z | 元に戻す |
| Ctrl + Y / Ctrl + Shift + Z | やり直す |
| F1 | 塗りつぶし／ワイヤーフレーム |
| F3 | 切断平面プレビューの表示／非表示 |
| 矢印キー | カメラ方向を基準にモデルを移動 |
| Esc | 終了 |

追加操作：カメラの旋回、上下移動、接近／後退は、Debug／Releaseの両方で使用できます。

| 入力 | 操作 |
|---|---|
| A / D | カメラの水平旋回 |
| W / N | カメラの上昇／下降 |
| U / M | カメラの接近／後退 |
| R | モデル姿勢とカメラをリセット。切断済み形状は維持 |

左右のCtrl／Shiftに対応します。Z／Yの押下開始時に1回だけ実行し、切断線のドラッグ中は履歴操作を受け付けません。取り消し／やり直しはメッシュ状態を復元し、カメラや表示用モデル変換は戻しません。復元成功時は古い平面プレビューを無効化し、表示設定は維持します。

F3は最後に作成を試みた平面を表示し、切断の成功を保証しません。Rは表示状態のみを戻します。元の形状へ戻す場合はOBJを再ドロップします。

## ビルドと実行

1. WindowsでVisual Studioのソリューション／プロジェクトを開き、C++17を使用します。
2. DirectX 11、DirectXMath、入力、D3DX11の依存関係を設定します。対応するヘッダー、ライブラリー、実行時依存関係が必要です。
3. 作業ディレクトリーからShaderとアセットを参照できることを確認し、ビルドして実行します。
4. 三角形化済みの閉じたOBJをドロップします。法線、UV、有効なMTL／テクスチャ参照を用意してください。
5. 切断後、F1で三角形を確認し、Ctrl+Z／Ctrl+Yで編集状態を比較します。

MTLとテクスチャはアセット内の参照先に配置します。インポーターが想定するOBJ／MTL形式を使用し、ASCIIパスと空白を含まない参照ファイル名を推奨します。ドロップしたパスはローダー用のWindows ANSIコードページへ変換するため、完全なUnicodeパス対応ではありません。

## モジュール構成

| モジュール | 役割 |
|---|---|
| `MeshCutter.h / .cpp / .inl` | 幾何、座標補助、クリッピング、輪郭、三角形分割、切断面生成 |

## 対応範囲と制限

- 平面切断を扱い、曲線の刃や任意の立体ブーリアン演算には対応しません。
- 単純な凹輪郭と複数の独立した非入れ子輪郭に対応します。穴は未対応です。
- 切断はサブセット単位です。材質分割で閉じた物体が開いた面へ分かれると、輪郭を閉じられない場合があります。
- 三角形の異なる3頂点が平面上と分類される場合、他の部分が両側にあっても更新を拒否します。両側頂点と閉輪郭の条件を満たせば、既存辺に沿う切断は成功する場合があります。
- 開いた／分岐した輪郭、入れ子、三角形分割の失敗では、部分的な形状を提出しません。
- 現在の16ビット形式では、置換後の展開頂点数を65,535以下に制限します。
- 履歴はCPU形状全体をメモリに保存し、件数／メモリ量の上限や永続化はありません。テクスチャは参照共有し、各履歴のGPUメッシュバッファは保持しません。
- 幾何の再構築を対象とし、コリジョン生成や剛体シミュレーションは行いません。

推奨デモ：立方体の切断 → 連続取り消し／やり直し → 取り消し後の新しい切断 → L字プリズムの凹断面 → F1／F3で確認 → OBJの再ドロップ。
